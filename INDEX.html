Scan India: state histories

Point your camera at a state’s QR plaque to read its story.

Each code holds a link to this page, like …?state=GJ. Anyone can scan it with their phone’s normal camera and the state’s history opens straight away. If the box above is empty, enter the public address where you host this page.

These codes only hold plain text like INDHIST:GJ, so a phone camera can’t open them. Paste the public web address of this page in the box above and the codes will become links.
